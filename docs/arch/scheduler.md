# 调度器 v1.1 —— 边际价值调度：打分、影子、灰度、ε 底

**它是什么**：把"进行中研究"统一成一张带族谱的前沿清单（frontier），每张
卡片打一个"下一发值不值"的分数，算力按分数投放。它不替模型做研究——
只对"下一次深化派发落在谁身上"给出机械建议；生成与评估的全部现有机制
不动。核心纪律是**影子先行**：默认只打分不执行（选点遥测可开、执行
灰度默认关），两级开关（影子开关／执行份额）独立回退，执行份额为零时
系统行为与现状逐比特一致。

**它的位置**：挂在推进治理回路的打分钩子上（每次状态组装时尝试一次
打分节拍，即 tick，两次之间至少隔 600 秒），读派生图事件流，输出 score
事件与（灰度开启时）选点行。

**上下游**：

| 方向 | 模块 | 关系 |
|---|---|---|
| 上游 | 派生图与事件日志 | frontier 节点、expand 快照（dsr 四元组＋池参数）、score/terminal 事件 |
| 上游 | 近失队列／审阅钟／收割 | 产物统一经 expand 事件入图（frontier 单一准入口） |
| 上游 | 多重检验现价重算 | Q 项与墙单位增益的数学底座 |
| 下游 | 选点行（点名通道） | 只含事实（哈希/操作/预算/键），由送达层消费 |
| 下游 | drain 判定 | 执行灰度下 frontier 非空不算 drained（收编） |
| 下游 | 周对账／重放 harness | 用事件流做受控评估（本篇八、九节） |

## 一、打分五项：A = Q + β·U + γ·D + η·E − λ·C

原始分项全量入 score 事件（离线反事实搜索权重的基础）；z 标准化只用于
tick 内排序，阈值与停止判断一律读原始项。缺项诚实置空，不编数。

### Q（墙换标度）——B 项墙数值锁 2.33／3.09

- **防什么**：用错误的运气线标度"离墙还有多远"。
- **怎么算**：Q＝Φ⁻¹(1−p_def)（Φ⁻¹＝标准正态分布的分位数函数，把
  p 值换算成"几个标准差"的标度），p_def 用评估快照的充分统计量＋池参数
  现价重算（纯函数）。墙高 b_N＝Φ⁻¹(1−1/N)——**N=100 → 2.33、
  N=1000 → 3.09，数值锁死**；不用 √(2lnN)（小 N 高估 20-30%）。层墙
  Θ_l＝√(1−ρ̄_l)·b_{N_l}（均衡相关下方差缩减的精确式）；全局尾概率用
  单因子蒙特卡洛补足。
- **边界**：重放场景不继承行为侧的采样器状态，墙用解析式（诚实声明：
  方向一致性足够，绝对值近似）。

### U（结构余地）

- **防什么**：只看离墙距离、看不见"还能怎么改"的结构余地。
- **怎么算**：三信号加权——状态切换可挖余地（必须过分裂样本复验门，
  不过则归零，不许单样本讲故事）、多腿可拆余地（可拆腿的因子给
  拆腿/重权操作）、离墙距离（(墙−t)/标准误，近失带内为正）。残差项
  预留、默认权重 0。缺项跳过、权重在可用项上归一。

### D（新颖度，分位校正）

- **防什么**：原始"1−最大相关"随参考集变大**机械趋零**（最大值是次序
  统计量，参考越多越大），失去区分度。
- **怎么算**：先算独立参考下的期望最大相关 E_ref＝σ_ρ·b_M（σ_ρ 用
  Fisher 近似 1/√(重叠天数−3)，M＝参考集大小），再取
  D＝clip(E_ref−观测最大相关, 0, 1)。观测相关只到随机能撞出来的期望
  水平 → D=0（不比随机新）；低于期望多少就是真新颖度——参考集变大
  不再机械塌缩。

### E（可扩展性，Thompson 族批次）

- **防什么**：对从没成功过的操作类型重复下注；以及把族内试验当独立
  样本虚增信心。
- **怎么算**：E＝Σ 各合法操作的 r̂ 采样值。**n 数族批次、不数试验**
  （族内试验不独立，每个"族×操作"算一批）；k 数该批内至少一次成功
  （成功＝批内任一派发的墙单位增益 g＞δ）。**成功判据 g＝(t 子−t 父)/
  b_{N_t}＞0.10**，且用派发时刻快照的计数与池参数计价——**决策时点
  冻结 null**（晚时代的墙更高，原始增益跨纪元不可比，除以当代墙高归一）。
  r̂ 用 Beta-Binomial 收缩（先验均值 0.1，小样本格子塌向族先验），tick
  内做 Thompson 后验采样——即不取后验平均值、而是从每个操作成功率的
  后验分布里抽一个随机数来参与排序：信息少的格子有机会被抽高、从而
  被探索，探索由概率匹配内生；随机数用确定性种子（同输入同输出）。
- **边界**：操作合法集：多腿因子额外给拆腿/重权，通用给加腿/截尾/
  状态条件/组合/滞后衰减/深化变体；历史命中率未积累的操作概率不虚标
  （恒记 1.0 并注明口径）。

### C（成本，κ=0 删除态）

- **防什么**：算力与统计资本的边际成本不进价格。
- **怎么算**：三段——槽位价（新候选 1、缓存命中 0.1：命中只付算力钱，
  不重复消耗统计资本）＋边际有效假设价（(1−ρ̄)/(1+(n_f−1)ρ̄)²，**族拥挤
  是折扣不是附加费**：族内第 31 发只消耗全新方向约 0.7% 的统计资本）＋
  族流入项 κ。**κ 经回归裁决后默认 0＝整项删除**（见成功样例）。

## 二、停止规则：退场孵化，拒绝非终点

视界（默认 7 天）内"至少一次成功"的概率 ≈ 1−Π(1−p̂_i)；低于 0.05 →
节点状态改为**孵化（incubating）**——停车但可重返（孵化→前沿是合法
迁移），终态只有入册/判死/证伪三种。拒绝不是终点，是让位。

## 三、分配：Thompson 分工 + ε 硬底 0.20

选点数按执行份额×(1−ε) 折算；**ε=0.20 的算力硬留给随机农场与新方向**
——多样性保险，不参与 Thompson 分工（不让"当前最优"垄断全部算力，
防止调度器把自己锁死在早期赢家上）。

## 四、影子模式（默认态）

- **防什么**：未经验证的打分器直接接管生产。
- **怎么做**：影子开关默认关——关闭时零行为；开启后每 tick（节流 600 秒）
  只打分、落 score 事件（必须带函数版本号——打分可复现的钥匙）、输出
  前五名摘要，**不挂任何选点**。遥测评估每 tick 上限 4 次（防饿死生产）。
- **红线（活动计数隔离）**：tick、打分、日志写入**零计入**线的活动数与
  试验数——打分不是挖掘活动，不得喂饱增长双轴、压制超时换向。

## 五、灰度执行：消费记账键 + drain 收编 + 逐比特回退

- **执行份额 >0 才挂选点**：每行只含事实（哈希、操作类型、预算、键），
  不含方向论证——方向是模型的事，调度器只管投放。
- **消费记账键**：每行带键 `pick:{hash}:{tick_id}`，试验派发（expand
  入账）命中点名目标时消费该键；**pending 未消费的同哈希不重挂**——
  会变键的重复挂出等于重注机（电平触发，不是边沿触发）。
- **drain 收编**：执行模式下前沿非空（含未消费选点）→ 不算 drained，
  旧的排空阶梯让位——算力落点由调度器点名。
- **逐比特回退（红线）**：执行份额=0（默认）时系统行为与现状完全一致，
  等价性有回归测试保障；影子开关独立于执行开关，权重改动必须走函数
  版本号递增＋回归测试，**禁止在线调权**。

## 六、expand 事件日志（常开）

事件日志是事实层，**独立于调度器开关常开**——关着调度器，图与事件照记
（详见[构造台账与派生图篇](derivation-ledger.md)）。这是影子期能够
回溯评估一切打分与投放决策的数据底座。

## 七、排序先行实验（零机制改动的纯内容实验）

开关默认关＝现状（近失队列按 p 升序）；开启后深化队列按最新 A 值降序
（没打过分的节点保持原序不虚挂）。验收指标＝**跟随率**：首位挂出后
48 小时内该节点或其子代是否真被派发——不跟则调度器退回遥测供给，
用户拍板去留。

## 八、周对账

配对＝决策时刻的父态分数 × 子代增益——**父态在子代评估时刻的池态下
重算**（同池态差分，公共的墙漂移在差分中消掉）。选点消费的派发与自由
派发**分臂**统计（自由臂是 ε 语义的故意次优，只对账不进功效判据）；
附分位校准（预测分数五分位 × 实现的均值增益——校准比相关更贴决策
质量）。连续数周相关≤0 只触发估计器复审标记，不自动改权重。

## 九、重放 harness：把轶事变成受控实验

五策略（均匀撒网／追高分／追新颖／追近失／边际价值）×两档预算，在真实
事件流上时间序重放：各策略只消费"真实发生过派发"的节点，按自身反事实
累计试验数重算墙（生成侧不可重放——未发生过的子代没有结局数据，本实验
测的是固定生成器下的**分配质量**）。主终点＝每单位算力的折减 t 增益；
功效所需样本数用影子期实测方差回填，不预编数字。

## 成功样例：κ 项按数据判死——三线全不显著，整项删除

调度器的成本项里曾有一个"族流入"子项（κ）：假设热门族的涌入会抬高池
分布、消耗额外统计资本，应按流入速率加价。上线前按预案做回归裁决：
三根线（全历史与分段）的检验统计量全部不显著——最大 |t| 只有 0.93，
符号一致性检查不通过。按预案默认执行：**κ=0 即删除态，整项移除，一行
代码不用改**（配置默认值即删除态）。这是调度器设计纪律的实录——打分项
的生死由数据裁决，不由直觉裁决；一个假设没挺过回归，就在它进入生产
之前死掉。

## 失败样例：60 发对 312 发——一条每臂 n=1 的轶事支配了通道偏好

历史上有一段著名对比：一场战役 60 发结构变体入册 6 只，同期纯随机农场
312 发入册 0 只。这个对比长期被当作"结构通道碾压随机通道"的证据，调度
器立项时它也是核心动机。复盘承认它的两面性：一方面它如实记录了重税墙
下随机边际趋零；另一方面它是**每臂 n=1 的轶事**——单场战役的条件、
当时的墙高、生成器版本都不可复现，据此做通道偏好决策与据单次掷硬币
做决策同级。重放 harness 的存在理由就是把它变成受控继任者：五策略同台、
反事实池态、实测方差回填功效——轶事可以当动机，不能当证据。

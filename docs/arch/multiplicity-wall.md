# 多重检验墙与 deflation —— 对"已经试过多少次"收费的墙

**它是什么**：因子挖掘每试一个因子，纯运气撞出好看数字的概率就多一分。
单次检验的"显著"只在"只试了一次"的承诺下可信；试了 N 次再挑最好的，
最好的那个天然偏高——这是选择运气，不是信号。多重检验墙的职责是把
选择运气折算进门槛建造费用：试验台账记下你试过的每一发，随机地形校准
出"纯运气大概能摸多高"，折减后的 p（deflated p）超过 0.05 一律不许入册。
**统计效力是消耗品**：被重复使用就贬值，墙随试验数单调升高。

**它的位置**：横在"评估完成"与"允许入册"之间。每次评估自动入账（自动
计算＝自动计数，堵住"挑着报"的可选停时），入册验收把 deflated p 当硬门。

**上下游**：

| 方向 | 模块 | 关系 |
|---|---|---|
| 上游 | 评估管线 | 每次评估的 IC 序列摘要、充分统计量是计价原料 |
| 上游 | 随机生成器 | 同通道生成随机树，造 null 地形（本篇第三节） |
| 上游 | 试验台账 | 试验单元去重、单调包络盖章（本篇第一、七节） |
| 下游 | 入册验收 | deflated p 是硬门（本篇第四节） |
| 下游 | 批量评估／尾部线 | 族口径与跨轨 Šidák（本篇第五节） |
| 下游 | 调度器 | 现价重算的墙数学是打分项 Q 的底座 |
| 下游 | 测试区一次性锁 | 本篇第八节 |

## 一、试验台账：试验单元与计价范围

- **防什么**：只报好看的、藏起试过的——选择性停报。
- **怎么查**：引擎层强制记账（与模型的叙事分文件）。试验单元＝（源码哈希,
  持有期）——重评同键＝更新不新增；不同持有期＝不同赌注，各算一发。每条
  记录带 IC 序列摘要（截尾 256 点）用于算试验间相关。
- **边界**：只收开发区/批量/组合三类阶段——**测试区不是试验**，它是消耗品
  的最终消费，把它的数字当试验基数等于把答案泄漏进准入门。
- **不过怎么办**：无——记账是强制的，模型没有不记的通道。

## 二、选择运气线：N 发纯噪声里最好一发能摸多高

- **防什么**：单发 p 值冒充全局结论。
- **怎么查**：对台账里全部试验的 IC 序列构建相关矩阵 R——两条序列尾部
  对齐（重叠 ≥60 点才实测，短重叠的相关几乎全是噪声；实测值带符号，
  正负对"最高线"同价且保留族间抵消结构），缺证据的对按独立计——独立是
  最贵的假设，缺证据就保守。再用公共随机数法从 R 直算期望最大绝对值
  E[max|X|]（σ 单位）＝选择运气线。公共随机数保证**加试验只可能抬线，
  不可能降线**（数学性质，非补丁）。
- **阈值**：M=1 也有底价 0.798——连符号都是选出来的（台账实证：曾有因子
  以负 IC 入册，符号事后翻转也是选择）。
- **边界**：先验注入只做小扰动（跨持有期相关先验兜底），半正定兜底投影
  仅在重建路径。

## 三、null 地形：随机基线怎么造、什么时候作废

- **防什么**：折减需要"池子分布的尺度"（池标准差）——没有基线就给不出
  可信的 p。
- **怎么查**：随机生成器用**与探索完全相同的通道**（含结构模板与占比）
  生成几十棵随机树，逐持有期跑完整口径的 IC_IR，得到经验分位分布——
  这就是 null 地形。池标准差取地形的标准差；尾部线的基线取 spread 段的
  经验标准差。同批树同时产出两段，保证条件一致。
- **指纹硬门**：地形写入时绑定指纹＝数据文件＋口径＋引擎版本＋**生效算子
  集**（算子名单、实现源码哈希、窗口/延迟/阈值采样集、模板占比）。任何
  一项变更（扩算子、改实现、改模板占比）→ 旧地形判失配 → 池标准差失效
  直至重校准——否则换数据集后旧基线仍在悄悄放行因子。
- **不过怎么办**：地形缺失或失配时**拒绝给出 p**（"先跑 null 校准建基线"）
  ——不给不可信数字，宁可保守重跑几分钟的校准。

## 四、deflated p 与入册硬门

- **防什么**：单因子 z≥3 但选择运气不可排除的因子混入账本。
- **怎么查**：对 IC 序列做偏度/峰度校正的 t 统计量，扣掉选择运气线
  （门槛 sr0＝E[max|X|]×池标准差）后算 p。入册验收三查：折减后 p≤0.05；
  p 不可算（缺池分布基线或样本不足）同样拒绝——**p=None 一律拒**，
  单发豁免不设（符号选择也是选择）。
- **边界**：提交入册时用四个充分统计量（sr、偏度、峰度、样本数）＋门参数
  重算 p——纯算术，不需要重评估；诊断里的关键数字若被手改过，回执校验
  会先一步拒收（防编造入册）。

## 五、批内族口径与跨轨 Šidák

- **防什么**：一批参数变体互相高度相关，按独立试验折减会高估墙、按单发
  又漏计族内选择；IC 轨与尾部轨双通道准入＝两次通过机会，单轨 0.05 的
  门槛实际放行率翻倍。
- **怎么查**：批内成员的 IC 序列构建 R → 同一 E[max|X|] 数学直接计价族内
  选择运气（替代旧的"有效个数"幂校正）；成员级失败隔离——坏成员标错误
  不烧整批，族口径只在有效成员上算。跨轨用 Šidák 二分（两条通道合用
  0.05 的总预算，均分后每轨门槛 α＝1−0.95^½≈0.0253）。
- **边界**：尾部线的族结构不看 IC 相关——IC 相关 0.75 的两因子，尾部
  持仓名单可能只重叠 0.4（尾部恰是因子分歧最大处），所以尾部账本用
  top-K 名单的指纹相似率（把每期持仓名单压成 128 字节签名，签名一致率
  ＝名单重合率的无偏估计）做贪心聚类，聚类数＝有效试验数。

## 六、分层 deflation 方案 B（影子期）：按出身层定价

- **防什么**："各发试验可交换"这个假设太粗——预注册的候选（评估前在预期
  台账里写过构造意图）与事后扫出来的候选，运气分布不同，应各配各的 null
  和额度。
- **怎么查**：评估前写过预期的候选进机制层独立采样器（层内自己的
  E[max|X|]），成员资格与时机证据（注册时间≤评估时间）、复杂度指纹（算子
  调用数、语法树深度）随账落盘。层间用 Šidák 分账（层 α=0.0253），层内墙
  Θ_l＝√(1−ρ̄_l)·b_{N_l}。
- **边界**：当前**只算不进门**——评估结果附影子字段（机制层 p、层 α），
  主门不动；是否翻转由影子期分布审查拍板，不预先承诺。

## 七、单调包络：灌水攻击的封顶

- **防什么**：灌高相关变体压低谱值、把墙"稀释"下去。
- **怎么查**：台账写盘时刻对合并后全量试验算一次有效数并盖章——后续任何
  灌水只能遇到"包络已封顶"的墙，包络只升不降。

## 八、测试区一次性锁

- **防什么**：反复消费测试区调参——测试区是最终裁判，只能看一次。
- **怎么查**：预约→计算→落锤三步原子化。预约在锁内检查"是否已消费/他人
  在途"，原子写入本进程预约后才开算；算完落锤记下谁、什么口径、什么结果
  消费了这次机会。此后任何再评直接拒绝："test 是最终消耗品，禁止反复
  评估调参。"
- **边界**：数据性失败（测试区无有效截面）不算消费，锁释放；计算崩溃
  残留的预约按进程存活检测回收——没算出结果就没被烧掉。

## 成功样例：重税墙下的两本账

同一时期的两条实录。一条战役线：60 发结构变体（加腿/拆杠杆/条件门）换来
6 只入册——结构先验在墙下仍有正边际；另一条纯随机农场线：39 批 312 个
随机成员，**零入册**——重税墙下随机的边际趋零，这正是墙的本意：随机树
的 IC_IR 分布就是地形本身，最好的随机树也只会停在地形最高处，过不了按
真实试验数定价的墙。账本同时留下裁决纪律：补挖清单 14 发复验 0 入册后
写下的结论是"当年放弃正确，确定性已买到"——墙挡掉的不是希望，是已经
定价过的运气。

## 失败样例：计价审计抓出一面虚高的墙

生产两根线上实测发现：旧版相关矩阵的建造方式是逐对用不同重叠段测相关
（估计互不一致，矩阵天然非半正定），再取绝对值抹掉符号——3662 个试验的
矩阵带 1360 个负特征值；半正定投影剪掉负特征值后残余一个巨型伪共同因子
（最大特征值占总质量约 32%），把弥散相关从真实的 0.165 虚构成 0.267，
选择运气线被推到 4.58σ——**超过独立试验的理论上限 4.35，数学上不可能是
诚实值**（独立重算 3.35）。修复三件：公共尾长一次构造（单一矩阵天然半正
定，不靠投影）；带符号相关；短重叠与重叠不足的对不进矩阵。这次审计确立
了本篇的原则：墙本身也要可审计——虚高的墙与虚低的墙同样是事故。

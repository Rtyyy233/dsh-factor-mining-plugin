# 构造台账与派生图 + 事件日志 —— 每个表达式的出身记账

**它是什么**：两件记账设施，一件旧一件新。**构造台账**是高思考强度轮的
手写工作记忆：每轮先读光标与已证伪清单，解剖新一批产物，把构造候选
入队，再回写——坑、裁决、欠账都记在人读的文件里。**派生图与事件日志**
是机器的事实账：节点＝试过的每个因子表达式，边＝派生操作（谁从谁
改出来的），事件流＝每次评估/判定/打分的原子记录。两者关系是
"一底座两投影"：图是底座，台账视图可从图自动导出——手写台账的记忆
负担由此有了机器替补。

**它的位置**：状态根目录下的追加式文件（图与事件各一份，一行一条）；
构造台账在分析工作区。事件日志**常开**，独立于调度器开关。

**上下游**：

| 方向 | 模块 | 关系 |
|---|---|---|
| 上游 | 评估管线 | 每次评估入账自动触发节点登记＋expand 事件 |
| 上游 | 入册判定 | terminal 事件（入册/拒/判死） |
| 上游 | 调度器 | score 事件与选点消费（via_pick） |
| 上游 | 农场/近失/审阅钟/收割 | 产物统一经 expand 入图（frontier 单一准入口） |
| 下游 | 调度器打分 | 读事件流最新快照（自足，不回读台账） |
| 下游 | 周对账／重放 harness | 事件流即实验数据 |
| 下游 | 台账投影 | 人类可读视图自动导出（只读） |

## 一、构造台账（手写层）：光标、清单与坑

- **它管什么**：工作记忆。触发循环＝读光标与已证伪清单 → 解剖新批次 →
  构造候选入队 → 回写。光标按**文件修改时间**分辨批次（批次周期号会因
  重启重置，不能当身份用）；已证伪清单防重挖；坑条目沉淀操作经验（如
  "烟测按指纹缓存拒绝，重交必须换指纹"、"除法构造先截尾防爆 inf"）。
- **配套清单**：补挖清单（手工欠账＋下一步）与深挖清单（已评自动收录）
  互补；循环规则（如"每清两条欠账才允许一个全新候选"）写在台账里由人
  执行。
- **边界（诚实声明）**：手写台账是记忆不是账本——重启覆盖、口径漂移、
  过时条目都可能发生（见失败样例）；机器事件账出现后，它的角色退为
  工作记忆与坑辞典。

## 二、派生图：节点、边与边来源三纪律

- **节点**＝试验过的因子（源码哈希即键），幂等登记——**同哈希首见冻结**
  （族谱不可事后改写）；状态是活的，走"尾行覆盖"。
- **边来源四选一（怎么挂边）**：
  - **点名回执**：深化点名/调度器选点触发的试验，父＝点名目标；
  - **农场种子**：随机出身的试验挂根（无父）；
  - **声明挂边**：模型自产的试验，按构造台账声明＋双信号（构造指纹
    ＋IC 谱）推断最近同族前驱挂边；
  - **诚实根**：推断不出的记无链根——宁缺毋假。
- **状态机**：前沿（活跃）→ 孵化（停车，可重返）→ 终态（入册/判死/
  证伪）。**退场进孵化池可重返——拒绝不是终点**。

## 二之续：挂边推断的执行序（引擎侧自动完成）

- **防什么**：挂错边——把独立试验误挂进家族（污染族计数与拥挤定价），
  或把点名派发挂成自由派发（污染分臂对账）。
- **怎么做（按序判定，先到先得）**：①随机出身 → 农场种子根；②点名命中
  ——待消费选点的目标与本条目满足同族判定（同哈希或双信号挂链）→ 挂
  点名边并**消费记账键**；③最近同族前驱（更早时间戳内、双信号挂链成立）
  → 声明边；④都不中 → 诚实根。同秒批内的先处理者可作前驱（锁内串行
  确定次序）。
- **边界**：事件日志上线前的存量节点没有快照，增益计算用图外台账兜底
  ——父态数字找得到就用，找不到就不算，不编造。

## 二之续二：查询原语与不变量检查器

- **查询原语**：父链回溯（到根为止，环即报错）、族根（父链末端）、全
  后代展开——调度器的族计数、拥挤定价、投影分组全靠这三个只读原语。
- **不变量检查器**（可随时跑）：图无环（逐节点回溯）、可重放变换逐一
  重放并对哈希、孤儿边清点（父不在图内的边——历史遗留可容忍、新增即
  异常）、边来源普查。检查结果被回归测试锁死——不变量被改坏会在测试
  里炸，而不是在生产里悄悄腐化。

## 三、五不变量

1. **图无环**——父链有限步到根（读端环检测，环即报错）。
2. **子表达式可复现**——注册表内的确定性变换（如拆腿）重放一遍，子代
   哈希必须一致；自由构造机械上不可重放，只验证父存在，诚实记。
3. **单写者**——全部写路径过文件写锁（追加式一行一条，崩溃残留的半行
   由读端跳过）。
4. **打分确定性**——同输入＋同函数版本号 → 同分数（调度器回归锁）。
5. **关闭等价**——调度器关着，图与事件照记事实账（事实层独立于开关），
   但不碰任何既有判定路径：全部挂点包错误保护，失败只写日志不阻断评估。

## 四、expand 事件：每次评估落账，重放自足

- **防什么**：事后回溯时"当时的墙有多高、池参数是什么"已变——用今天
  的参数审判昨天的决策。
- **怎么记**：每次评估入账自动落一条 expand，除身份字段（子哈希/父哈希/
  操作/边来源/线/出身/持有期/阶段）外，**快照自带**：充分统计量四元组
  （sr＝信号强度统计量、偏度、峰度、样本数）、当刻池参数（选择运气线、
  池标准差）、
  现价重算的 p 与 t、**墙单位增益**（父态在子代池态下重算——同池态
  差分，公共漂移消掉）、父态分数、近失旗（0.05＜p≤0.30）、族名、算力
  消耗。r̂ 累积、周对账、重放全部自足于事件流，不依赖事后台账重读。
- **new_candidate 开关**：该（哈希，持有期）**首次出现才计新候选**（消耗
  统计资本），缓存命中只付算力钱——防重复入账虚增墙。
- **via_pick**：被调度器点名消费的派发带消费键——分臂对账的依据。

## 四之续：红线——记账不是挖掘活动

图与事件的一切写入**零计入**线的活动数与试验数。这条红线防的是一个
反身性漏洞：如果记账本身被算成"活动"，一个只会在图上刷节点的会话就能
喂饱增长轴、压制超时换向——账本必须对它所记录的过程保持中立。同理，
缓存命中的重评只付算力钱、不重复计试验——账本计价的是新的统计赌注，
不是新的 CPU 时间。

## 五、terminal 与 score 事件

terminal＝入册判定（入册/拒/判死，带当时的 t 与 p）；score＝调度器打分
（原始分项全量、排名、策略、是否执行，**必须带函数版本号**——重放可
复现的钥匙，缺版本号直接拒绝落账）。

## 六、台账投影：自动导出的人类可读视图

按族根分组导出（族→边（操作/来源/时刻/线）→终态标注），只读不改账——
导出视图替代手写台账的"族谱"部分；坑、裁决等叙事仍归手写层。边界：
投影有族数上限，账本以追加文件为准。

## 成功样例：四账一币——四个通道归一记账

expand 事件上线前，近失带、收割、审阅钟产物、自由试验各有各的记账
通道，调度器想统一打分就得拼四份口径。上线后四账一币：**全部产物统一
经 expand 事件入派生图，frontier 成为单一准入口**——不在图上的近失
候选自动补登记为无链根。旧通道标注弃用但不删（历史账可读）。调度器
打分、周对账、重放从此只读一份账。

## 失败样例：手写台账的三次教训（机器账的出生证明）

教训一，**重启覆盖**：一夜四线农场文件口径 768 个成员，其中两条线各自
重启过一次、周期号被覆盖，实际成员数更多——文件口径系统性低估，复盘
只能标注"含重启覆盖低估"。教训二，**过时未付项差点重做**：台账补挖
清单里记着"三元加相关腿成四元"是待付项，核对入册账后发现它两天前
已经入册——当即标注"实已支付，防重做"；若无此核对，一次完整的构造
＋评估预算会被浪费在已付账上。教训三，**经验靠人记**：烟测门按指纹
缓存拒绝、同源秒拒这个坑，靠台账口口相传，新会话仍会再踩一次才学到。
三者共同指向：身份、欠账、经验都需要机器可重建的事实层——派生图管
出身与状态，事件流管决策时刻的全部参数，投影管人读。手写台账不再
承担"账"的职责，只承担"记忆"的职责。

## 这套文件是什么

对两个系统（因子挖掘、投研）× 两侧宿主（DSH 家族、zcode），盘点一般生产实例中所有可能情境下**模型实际看到的全部上下文**。每个情境一张卡，五字段：编号与名称／触发时机／完整上下文（逐字全文）／溯源与设计功能／条件与现状备注。静态长文（系统提示全文、注入策略文本全文、技能正文、工具 schema 全文等）收在各文件末尾的附录，卡内引附录号。

工具面本身立卡：工具的名称+描述+参数 schema 全文是模型行为的塑形源，视作上下文的一部分。

## 两句使用说明

1. 找"某情境下模型看到什么"：按上表进对应文件，按卡号定位；跨通道同源的内容（同一条指令文本出现在工具应答和主动注入里）各卡已互相注明。
2. 架构文档（`docs/HARNESS_ARCHITECTURE.md` 三通道送达等章节）引用本目录卡号（如 F-DSH-03），不重复收录。

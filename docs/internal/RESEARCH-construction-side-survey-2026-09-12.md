# 构造面可参考工作调研

- 日期:2026-09-12
- 背景:前一轮盘点确认本系统"打分器厚、教练零"——评估面完整,构造面(指导 LLM 往哪挖/怎么改/值多少钱)无任何机制。本调研搜集外部可参考工作,按四条空缺组织:
  - **(a) 正向定位**:哪片构造空间还没挖/可能有信号;
  - **(b) 归因→操作语义翻译**:把评估结果翻译成"下一步该改什么构造";
  - **(c) 边际价值事前反馈**:候选对在册账本的增量值多少钱(对应 S3);
  - **(d) 改进动作的循环位置**:失败/接近候选不被关闭,成为后续构造的输入(对应"失败即关闭"缺环与 deepdig 雏形)。
- 方法:web 检索定位文献(arXiv/NeurIPS/KDD/AAAI/券商研报),本文仅收录检索可核验条目;对本项目已有的零件(家族几何/null 地形/near_misses/trail)逐一标注,避免把已有的当缺口。

## 家族一:表达式空间搜索(GP / RL)——把"教练"内化为策略

这一族不显式指导任何人:它们把构造空间(算子树)当作搜索空间,用适应度信号训练一个"生成分布",指导以内化形式存在。对我们的价值不在照搬算法,而在**奖励/目标的三个设计决定**。

### 1.1 券商遗传规划实务线(华泰系,2019-2021)

- 华泰人工智能系列二十一《基于遗传规划的选股因子挖掘》(2019-06):深度定制 gplearn,预测目标=未来 20 日收益,适应度=IC 族,从量价数据挖出 6 个增量因子。
- 系列二十三:适应度改**互信息**(非线性依赖也能被抓到——RankIC 线性度量会漏的象限)。
- **GPU 加速篇(关键)**:"每轮挖掘以**剔除上一轮新因子后的残差收益率为目标**,适应度为样本内年化 RankICIR"。这是**边际价值反馈到构造侧的最早实务形态**:不在提交期拦冗余(我们的正交门),而是在目标侧把账本已解释的分量剔除,让搜索直接面向残差 alpha。**y 侧正交化**。
- 东方证券 DFQ 系统、Alpha101 再扩展(风格中性化后仍有效=增量验证):同一范式的工程化延伸。

### 1.2 RL 线

- **AlphaGen**(KDD 2023,[arXiv:2306.12964](https://arxiv.org/abs/2306.12964)):RL 逐 token 生成表达式,**reward = 候选加入下游组合模型后的组合性能增益**,而非单因子 IC——协同集(synergistic set)导向。这是空缺 (c) 的直接学术形态:**组合层边际价值做生成奖励**。配套池更新机制按边际贡献保留成员。
- **Alpha²**([arXiv:2406.16505](https://arxiv.org/abs/2406.16505)):DRL 把因子发现形式化为程序构造,显式优化**逻辑一致性与多样性**。
- **AlphaForge**(AAAI 2025,[arXiv:2406.18394](https://arxiv.org/abs/2406.18394)):生成-预测网络,**算子选择即动作**(树构造过程),两阶段"挖掘+动态组合";后续者 AlphaQCM(分布式 RL)、Alpha-GFN([github.com/nshen7/alpha-gfn](https://github.com/nshen7/alpha-gfn),GFlowNet 按比例采样多样解)。
- 教训对照:这些系统全部**没有知识型教练**——指导信号全是评估器给的。与我们"验证死约束、表达自由"哲学同构;差别是他们把评估信号**回灌到生成分布**,我们目前止步于报告。

## 家族二:LLM 进化循环——与我们架构同构的成熟形态

FunSearch/AlphaEvolve/ReEvo 的架构 = 我们的架构(引擎 evaluator + LLM generator),它们多出来的三件事正好是 (a)(b)(d)。

### 2.1 FunSearch → AlphaEvolve(DeepMind)

- FunSearch(Nature 2023):LLM 只写一个函数,自动评估器打分,**program database**(island 种群模型)存精英,精英回灌 prompt 指导下一代变异。
- **AlphaEvolve**(2025,[DeepMind 博客](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/)):升级为演化整个代码库;**多模型级联**(Flash 贱模型出大量提议 + Pro 贵模型精炼);程序库带**谱系(lineage)与进化存档**——每个程序可追溯其祖先与变异史。
- 对读:我们的 `trail_engine` + 源码外挂库(按 source_hash 可回溯全文)在**事实层面**已是 program database 的等价物;缺的是**精英回灌通道**——评估通过的父代源码+关键数字没有被组织成下一代构造的 prompt 素材(现在只在 agent 上下文里自然滚动,50+ 轮后被淹没——正是 Prompt 干预实验诊断的"长上下文退化")。

### 2.2 ReEvo(NeurIPS 2024,[arXiv:2402.01145](https://arxiv.org/abs/2402.01145))

- 机制:进化搜索 + **LLM 反思(reflection)**——从**失败候选**中提取洞察(glean insights from failed ideas),反思文本作为"学术综述"注入后续生成。
- 精确对应空缺 (b)+(d):失败即关闭的反面是失败即输入;归因翻译的载体是**结构化反思文本**而非数值遥测。ReEvo 证明了这一通道在组合优化启发式上有效(NeurIPS 2024,450+ 引用)。
- 对读:我们的 S1"拒绝即信息"只把拒绝原因**返回给被拒者**,没有把失败洞察**积累给后来者**。trail 的 `new_information`/证伪三条件字段已存了素材,缺一个"反思聚合"通道。

## 家族三:LLM 特征工程与智能体——反馈环的最小形态与知识载体

### 3.1 CAAFE(NeurIPS 2023,[arXiv:2305.03403](https://arxiv.org/abs/2305.03403))

- 机制:LLM 迭代生成特征代码,critic=内部 ML 模型的交叉验证增益,反馈结构化回传,**同时产出每个特征的自然语言效用解释**。
- 参考点:这是"评估反馈→生成"环的最小完整实现;其**特征级解释**是可审计的(每轮都说清"这个特征为什么有用/没用")。非 LLM 对照:OpenFE(KDD 2023)证明树模型增益+逐级减半可以在无 LLM 下做特征生成——指导的关键是**结构化增益反馈**,不是生成器智能。

### 3.2 Alpha-GPT 系(微众银行/人大)

- **Alpha-GPT**([arXiv:2308.00016](https://arxiv.org/abs/2308.00016),EMNLP 2025 Demo):自然语言研究思想→因子表达式的 prompt 工程框架;人类研究员与 LLM 在因子空间与语义空间两个层面交互。
- **Alpha-GPT 2.0**([arXiv:2402.09746](https://arxiv.org/abs/2402.09746)):全管线 human-in-the-loop;分析层构建**金融行为知识图谱**——把领域知识(论文/研报的因果与行为逻辑)组织成可查询的构造先验库,供挖掘智能体检索。
- 对读:知识图谱是空缺 (a) 的"知识侧"答案——我们的文献灵感通道(灵感重置:literature)目前是**无结构的**(让模型自己去想论文),图谱化=把"往哪挖"的先验变成可检索资产。但注意成本量级:Alpha-GPT 2.0 是一个团队级工程。

### 3.3 多智能体辩论系

- AlphaAgents([arXiv:2508.11152](https://arxiv.org/abs/2508.11152)):LLM 多智能体协作与辩论做投资决策;FactorMAD(ACM):多智能体辩论挖可解释因子;另有风险感知三阶段策略发现框架([arXiv:2409.06289](https://arxiv.org/abs/2409.06289))。
- 对读:辩论=用多视角互批模拟教练。**与我们 N4 证据冲突风险最高的一族**:引擎注入指令已实证推高冗余(15.8% vs 11.1%)、期望式创新 prompt 推高 novelty theater(86% vs 67%)。多角色注入若不携带新信息,只是把同一模型的先验换着腔说。谨慎吸收:角色可以,但每个角色必须绑定**该角色独有的数据面**(如"组合层角色"必须真的算 ΔENB 才有资格说话)。

## 家族四:质量-多样性(QD)——把"账本维度"做成搜索目标

- **Novelty search**(Lehman & Stanley 2011):抛弃目标函数只奖励新颖行为——欺骗性地形(deceptive landscape)的解药。因子空间的对应物:信号贪婪导致的单一栽培(会话 top1 族 57-96%)正是目标欺骗的实证。
- **MAP-Elites**(Mouret & Clune 2015):行为描述子定义 niche 网格,每格存该 niche 的精英,搜索向**空格与低分格**倾斜——"照明(illumination)"整个搜索空间。CVT-MAP-Elites 解决高维描述子;VQ-Elites(2025,[arXiv:2504.08057](https://arxiv.org/abs/2504.08057))让描述子本身无监督学习。
- 对读(本调研最重要的映射):**我们的正交门/家族 MinHash 几何已经是 QD 的描述子雏形**——top-K 名单 Jaccard/IC 相关矩阵就是行为描述子,在册账本就是 archive。QD 的成熟答案补上我们缺的半句:**空格本身就是正向定位信号**。MAP-Elites 视角下,"往哪挖"不是预测问题而是地图问题——把账本投影到描述子网格,空格与低分格列表就是引擎可机械产出的"未开采区域清单"(空缺 (a) 的零知识版本,不需要任何预测模型)。我们的反面清单已天然一致:QD 不拦灰带(合法变体区),只对"格子里已有精英"的重复计价——与"0.6-0.8 灰带是合法变体区,拦它等于杀深挖"的裁决同构。

## 家族五:边际价值与组合层定价(空缺 (c) 的数学骨架)

- **López de Prado 系**:HRP(2016)/NCO(2019)/**有效注码数 ENB**(《Machine Learning for Asset Managers》):按相关聚类把组合风险分解为不相关注码,ENB=有效独立维度。**新因子的边际价值 = ΔENB**(入册前后各算一次,账本级可闭式计算)。
- **华泰 GPU 篇的残差目标**(§1.1):x 侧 vs y 侧两种边际化路径——ENB/正交门在 x 侧(因子空间)计价,残差收益率在 y 侧(目标空间)剔除。y 侧更彻底:搜索目标本身就是"账本还没解释的部分"。
- **AlphaGen 组合奖励**(§1.2):x 侧计价的 RL 版。
- 三者共同点:边际价值**事前可算、机械可算**,不需要人类判断——这正是 S3 需要的性质。

## 与本项目实验证据的对读(红线)

1. **指导=信息供给,不是动机灌注**。双阴性实验证明生成层无新颖性缺陷、逃逸是默认行为;病灶在 loop。故一切构造面机制应给模型**它自己算不出的东西**(ΔENB、残差序列、空格地图、失败族谱),而不是叫它"更有创意"——后者已实证无效且诱发 novelty theater。
2. **注入以遥测形式,不以指令形式**。N4:引擎注入"深挖补正"使冗余率 15.8% vs 自主 11.1%。AlphaEvolve 的精英回灌是"素材+分数",让模型自己决定怎么用——不是"你应该深挖 X"。
3. **多角色/辩论须绑定独占数据面**(§3.3),否则是先验复读。
4. **残差目标与正交门的对偶要管理统计口径**:残差目标把"账本已知"内化进构造,但每轮正交化会累积账本估计误差(在册因子权重自身的过拟合),dev 区内闭环可接受,必须防止残差序列进 test 语义——与 tail_ledger 的 stage 过滤同一防线。
5. **QD 与灰带裁决一致**:不拦 0.6-0.8(合法变体区),只对"格内已有精英"的重复计价——外部成熟理论与本项目 09-08 裁决互证。

## 优先级建议(供拍板,未展开为任务书)

按"实现成本×与现有架构咬合度"排序:

1. **ΔENB 边际遥测**(纯计算,账本侧闭式;直接落 loop 响应,作为 selection_cost 的账本级扩展)——S3 的最小可用形态。
2. **near-miss 工作清单引擎化**(deepdig 升格:trail 派生+自动维护+跨会话持久,现有 `tail_near_misses` 已是内核)——空缺 (d) 的机械解。
3. **残差收益率目标接口**(y 侧边际化;华泰路线;风险见红线 4)。
4. **QD 空格地图**(家族几何网格化,输出空格/低分格清单)——空缺 (a) 的零知识版本。
5. **失败反思聚合**(ReEvo 路线,trail 证伪字段已存素材)。
6. 知识图谱(Alpha-GPT 2.0 路线)——工程量级最大,远景项。

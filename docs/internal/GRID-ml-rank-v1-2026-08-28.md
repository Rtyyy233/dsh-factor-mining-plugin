## 4. 实现注记（2026-08-28 实现期补录，首次运行前——冻结纪律内）

跑前修订（尚无任何试验按旧口径入账；T-EW 首跑 27c1193 不受影响）：

- **refit 年频 + 再平衡月频**（原「refit=与再平衡同频（月）」修订）：
  审计/扰动族每 evaluate 重放整条管道数十次，月频重训的 LightGBM
  成本不可行（~113 fits×37 管道）；ridge 的 Gram 流使年频近零成本。
  两臂统一年频重训（同构），月频再平衡仍用当年模型对新特征行重打分。
  真实面板实测：T-G1 全 WF 管道 37.5s（stride=5）。
- **TRAIN_STRIDE=5**（GBDT 臂）：训练行按日 stride 抽样——重叠标签
  冗余抽样，统计上近零成本，计算 5× 缩减。T-R* 不抽样（Gram 流本就
  全量）。
- **EXPECTED_LGBM="4.7.0"**：G 臂源内 assert 版本，漂移 = fail-closed。
- **ok_pred / ok_train 分离**：选股候选掩码 = 池 ∧ 特征有限；训练掩码
  另加标签有限。标签有限性含未来价（t+h），混入候选集会破截断不变性
  （实现期自查抓出）。
- **wf_config = {n_folds:1}**：策略内建 expanding 年度重训已是 WF 本体；
  外层折只做重复计算，n_folds=1 + 内部 WF = 等价且无冗余。
- 生产 refs 文件：`.strategy-lab/feature-card-2p3.json`（5 哈希，均
  horizon=20 入指纹）。

## 5. GBDT 收敛诊断（2026-08-28，用户质询触发；scratch 口径零计价）

**问题**：n_estimators=300 是先验冻结，未做过收敛检验。

**方法**：对每个 dev 内年边界 y（2018-2024），训练 [0, y−25)（与
T-G1 完全同构、stride=5、seed 42），验证 = **次年实际应用窗**的逐日
Spearman IC 均值（决策口径，非 pooled MSE——MSE 与 top-k 决策错位，
见损失轴讨论）；600 棵单模型按 num_iteration 切片取 10/25/50/100/
200/300/450/600 的 IC。

**结论：300 在平台上，不是欠拟合截断**。7 边界年均 IC：10:+0.011 →
50:+0.017 → 100:+0.019 → 300:+0.019 → 600:+0.018——[100,600] 区间
波动 <±0.001，加树无增益。逐年看多数年份峰在 25-100 棵后缓降（轻
微过拟合方向）；仅 2024（dev 段）从负值爬到 +0.024@300。诊断同时
解释了 T-G8（rolling）> T-G1：2020 与 2023 两个负 IC 年（regime
翻转），老数据在翻转后拖累 expanding 窗。不引入 early stopping
（平台平坦，预算选择不敏感；冻结维持）。

**附带参照**：真实 T-R1 特征集（11 特征含乘积）同窗年均 IC ≈ 0，
GBDT ≈ +0.019 且 7 年中 7 年 ≥ ridge——IC 层优势广布，但组合层差距
（0.81 vs 0.77）远小于 IC 层差距；正式结论仍以预注册收益差裁决为准。

**事件披露（诚实台账）**：诊断第一版把 2024 边界验证窗写到
[2024-01, 2025-01)，越过 sel_end 约 70 天——**test 段的日均 IC 被看
过一个混合窗口数字**（+0.042）。未据此做任何配置决策；dev 裁剪重算
后结论不变（年均由 7 边界主导）。教训：手工诊断脚本绕过了 harness
的 _dev_env 切区保护——诊断也必须显式裁 sel_end（本节即为流程修正）。

## 6. 训练实现 review（2026-08-28，用户指令；一处规格偏差修正）

**核对结论（逐环节，对照任务书 §7）**：purge 数学（训练行 t <

截面化（无跨时归一化=无泄漏通道）✓；候选/训练掩码分离 ✓；折/年界

0.764/0.758/0.772（无截距旧值 0.769/0.760/0.754）——最优 ridge 由
R1 变 R3(0.772)，复杂度门差距量级不变；旧三条目留账作废不删。

**G 臂不受影响**：T-G1 在修正版 mlrank 下逐位复现生产数字

**暴露的门校准问题（已修，D14）**：旧延迟门「任何不降 = 红旗」对

**T-R2r（post-hoc 补格，用户拍板）**：T-R2 + rolling 3 年窗，完成

2023/24 领先）后提出，单独计价（试验 #16，Sharpe 0.805/年化 14.2%），

**裁决工具**（`dsh_strategy_lab adjudicate`；只读已入账运行，零新
测量）：同窗 [2018-01-02 → sel_end]（暖机后），日收益差按日 block
bootstrap（块 20），预注册判据 = 90% 下界>0、平局归简单（D12/D13）。

**裁决结果（13 臂全，块长 20）**：

| 对照 | 年化差 | 单侧 p | 判定 |
|---|---|---|---|
| 存在性：最优线性(T-R3) − 等权 | +15.2% | 0.003 | **赢（信号存在）** |
| 复杂度：最优G(T-G4 含周频) − T-R3 | +3.7% | 0.066 | 平局归简单 |
| 复杂度·月频匹配：T-G7 − T-R3 | +1.4% | 0.117 | **平局归简单** |
| 适应性·GBDT：G8−G1 | +1.7% | 0.070 | 噪声内 |
| 适应性·线性：R2r−R2 | +1.0% | 0.181 | 噪声内 |
| 模型类·滑窗内：G8−R2r | +0.9% | 0.279 | 噪声内 |
| 频率轴：G4−G1 | +3.8% | 0.069 | 噪声内（接近未过线） |

**预注册结论**：
1. 存在性门过——特征组合对等权的增量在带外（+15.2%/年，p=0.003）。
2. **复杂度门不过 → 网格胜者 = T-R3（线性，λ_ratio=1e-2）**——
   GBDT 的复杂度未在 90% 下界证明自己；平局按 D12 归简单。
3. 「适应性 > 模型类」工作假设：点估计方向一致（rolling 两臂均
   +0.04~0.05 Sharpe）但**全部落在噪声带内**——dev 窗内不可裁决；
   与模型类差异同量级且同样不可分。频率轴（周频）p=0.069 最接近
   但未过线，不得翻案。
4. 用户先前的直觉（适应性更关键）作为方向被数据兼容但不被数据
   判定；若要在 test 后继续追问，需新预注册文书（样本量是瓶颈，
   不是模型）。

## 11. 重大事故：未复权分级基金折算污染（2026-08-29 发现；用户 ≤10 槽位
需求触发的书宽诊断中暴露）

**事故链**：用户提出持仓 ≤5-10 的真实约束 → 书宽衰减诊断需先复现生产
管线 → 校准点对不上（top-20% 复刻 Sharpe≈0 vs 生产 0.772）→ 逐层排查
（源码/因子源/env 逐位一致；日序列 lag-0 相关 0.845 但均值差 8.4bp/日）
→ 定位 2018-08-08 SZSE.150212 收盘 0.253→1.027（复牌日 4.06×，事件日
前 NaN 停牌一天）。

**根因**：面板含 2015-2020 深市 150xxx 分级基金家族，份额折算/合并事件
**未复权**——全面板 |ffill 日收益|>50% 事件 206 个，全部为复牌日跳变
（2015:98 / 2016:21 / 2017:10 / 2018:50 / 2019:10 / 2020:16 / 2021+:0，
与分级基金 2020 退场一致）。模拟器 `_ffill_close` 对停牌 NaN 前收估值、
复牌日按未复权新价记账 → 持有人账本凭空 +300%；且引擎「每开盘向昨收
目标回补」在假跳变后立即减仓**兑现**假收益并复投 → 复利放大。反转+流动性
因子系统性选中这类高波动标的 → 假 P&L 集中在策略书而非全池。

**对照实验（同一条 T-R3 权重路径，零新试验）**：

| 口径 | 年化 | Sharpe | 回撤 | 总收益 |
|---|---|---|---|---|
| 生产（现行引擎+未复权面板） | 13.7% | 0.77 | 29.0% | +232.7% |
| A 复权面板（206 事件前史×跳变因子，引擎不变） | **−0.25%** | **0.065** | 48.8% | **−2.3%** |
| B 月频持有语义（未复权，只在目标变更日交易） | 10.5% | 0.60 | 36.0% | +54.9% |

逐年对差（生产−复权，log）：**全部差距在 2018**（+0.624 vs −0.602，
差 1.226 log≈240pp；2019-2024 逐年逐位一致）。生产 13.7%/年 ≈ 2018
一个假年份的复利。

**等权锚同口径**：生产 3.4%/0.325 → 复权 **0.97%/0.140**。复权后
**T-R3 输给等权锚**——存在性裁决（R3−EW +15.2pp p=0.003）**反号**，
不只是削弱。注：对照中策略路径固定（权重按未复权信息选出），是污染的
下界估计；干净复评需整条管道在复权 env 上重跑（模型标签本身也吃了
+300% 假标签：0.253→1.08 的 20 日前向收益是有限值，进过训练集）。

**波及面**：
1. 本 GRID 全部 17 臂、§8 裁决、§10 submit 五门与入册（ml-rank-v1-t-r3）
   ——数字无效，registry 条目应隔离（建议加 quarantine 标注，不动数据）；
2. 因子层：5 特征卡因子（及任何 2015-2020 窗口验证过的入册因子）在同
   面板上挖出，IC/门链同污染，需复权后复验；
3. harness 本身无 bug（复放逐位一致）——缺陷在**数据管道未复权**，
   ffill 估值语义在复权数据上是正确的。

**修复顺序（待用户拍板）**：R1 env 缓存复权重建（≥±20% 复牌跳变全检
测；或从数据源重拉带复权序列）→ R2 策略层复评（诊断级先行）→ R3 因子
层复验 → R4 才回到 ≤10 槽位新网格（用户 2026-08-29 真实约束）。**test

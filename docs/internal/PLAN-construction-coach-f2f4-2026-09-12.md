## 一、核心综合:两个家族共用一个底座

家族二与家族四在文献里是两条线,在我们系统里是**同一底座的两个查询面**:

```
trail_engine(已有,唯一事实源)
   │ 派生:每条试验附行为描述子(衰减半衰期/换手/域——evaluate 已算,零新增计算)
   ▼
账本地图 archive(新,纯派生视图,可随时重建)
   ├─ 查询面 1:cell_map(家族四)——网格占用/精英/空格清单 → 正向定位
   ├─ 查询面 2:elites(家族二)——按族/按格返回精英源码指针+骨架数字 → 精英回灌
   └─ 查询面 3:lessons(家族二)——按族/按弧聚合失败事实摘要 → 失败反思
```

三面全部是**拉取式工具 + loop 响应摘要**,零指令注入——N4 红线(注入使冗余 15.8% vs 11.1%)与双阴性实验结论(生成层无缺陷,缺的是信息供给)在形态上直接满足。

## 二、机制设计

### 2.1 行为空间地图(MAP-Elites 移植)

**描述子轴(从现有诊断直取,不新增计算)**:

| 轴 | 取值来源 | 分箱建议 |
|---|---|---|
| 信号半衰期 | IC 衰减曲线半衰期(evaluate 已算) | {≤5d, 5-20d, >20d} |
| 换手频率 | 换手率定价层已算 | {低,中,高} 三分位 |
| 暴露域 | 构造指纹域标签 / beta 暴露主向 | 域枚举(≈5-8 个) |

即约 50-150 格,无需 CVT。**分箱依据**:MAP-Elites 文献的行为描述子(bahavior characterization)选择是成败关键(Meyerson GECCO 2016;VQ-Elites 2025 以无监督学习描述子为贡献,反证手工描述子易错)——因此轴选**行为空间而非构造空间**:构造空间的空格可能是语法上不可达/语义上无意义的区域,行为空间(信号怎么活/多久换手/暴露在哪)的空格才有"未开采象限"的语义。

**每格精英**:格内质量最高者。质量函数默认 dev 区 IC_IR(deflated p 为辅);D7 可换 ΔENB 贡献。

**cell_map 输出**(loop 响应摘要 + `factor.cell_map` 工具全量):
- 占用格:精英名+骨架数字(不推源码,源码走 elites 面);
- 边缘格:已占用但质量 < 某阈(挖过没挖好——比空格更 actionable 的信号);
- 空格清单:与占用格相邻的空格(孤立空格不列,避免把 agent 推进无意义区域)。

**与 deflation 的口径自洽**(须写进实现注释):把探索导向空格会改变试验生成分布——这不破坏任何现有统计:E[max|X|] 在**实际试验集**的实测相关矩阵 R 上计价(分布变了 R 跟着变,门自适应);pool_std 是 landscape-only 的随机 null,与试验分布无关。唯一要求:空格清单只描述"哪里没挖",不得携带任何格内历史数字的方向性暗示(那是 agent 自己的推论工作)。

### 2.2 精英回灌通道(FunSearch/AlphaEvolve 移植)

- `factor.elites` 工具:输入(族/格/horizon/前 K),返回精英条目:名字、构造骨架(算子序列,非全文)、关键数字(IC_IR/deflated p/半衰期/换手)、source_hash 指针(全文经既有源码外挂库 `factor.source` 取,已有机制)。
- **弧边界再锚定**(治长上下文退化的关键):loop 响应在方向预算耗尽/族链断裂/灵感重置时,附"本弧精英骨架"压缩块(≤5 条)。依据:Prompt 干预实验证明**先例醒目时逃逸是默认行为**——长会话的重复不是模型不会逃,是先例被 50 轮工具结果淹没;再锚定=把醒目还给先例。
- 谱系(AlphaEvolve lineage 的等价物已存在):指纹相似度链即谱系,elites 返回值附"最近祖先"(最相似先例),无需新建。

### 2.3 失败反思通道(ReEvo 移植,引擎编译事实+智能体写解释)

分工(对应"agent 数字先对账再采信"纪律):

- **引擎侧编译 `lessons`**(纯结构化聚合,零 LLM 参与,杜绝编造史):按族/按弧聚合——试过什么(构造指纹族)、怎么死的(门拒绝原因分类:G1/G2/G3/正交/同构;near-miss 差距数)、相互关系(与精英的 ρ̄)。ReEvo 的"从失败候选提取洞察"在我们的约束下必须落地为**事实摘要**,因为我们的证据表明 LLM 自由发挥的"反思"会滑向叙事(novelty theater 86% vs 67%)。
- **智能体侧写反思**:agent 读 lessons 后在 `record_trail` 写自己的解释(字段已有:new_information/证伪三条件),**S2 宣言门对账**(已有)——解释与事实不符即拒收。
- 反思的消费者是 agent 自己的下一轮规划;引擎不把 agent 反思再注入回 loop(防二阶复读)。

| 既有件 | 关系 |

| deepdig_worklist.md / catchup_factors.md(会话层 markdown) | 被 cell_map+elites **取代并引擎化**(其"每轮先清此单"规则由 near-miss/边缘格遥测自然继承);存量清单首清后退役 |

## 三、拍板点

- **D1 描述子轴**:推荐"半衰期×换手×域"(上表)。备选:horizon 申报值替代半衰期(更粗但更稳);beta 暴露替代域标签。风险:半衰期估计噪声大时改用 horizon。
- **D2 精英资格**:仅入册者,还是含 near-miss(p<0.15)?推荐**含 near-miss**——FunSearch 的 program database 存的是评估分高的程序而非仅"通过"者;我们的 near-miss 正是"格内最好但差一口气",对生成侧信息量最大。红线:精英**资格**放宽不等于**入册**门放宽,两轨严格分离。
- **D3 反思分工**:推荐"引擎编译事实+agent 写解释+S2 对账"(§2.3)。备选:纯引擎(信息量低)或纯 agent(编造史风险)。
- **D4 通道形态**:推荐"拉取工具 + 弧边界推送摘要"(§2.2)。纯拉取会让 agent 忘了用;高频推送回到注入老路。弧边界是折中:换向时刻正是需要再锚定的时刻。
- **D5 loop 响应预算**:精英骨架/空格清单的 token 预算(建议合计 ≤400 token/次,工具全量另计)。
- **D6 范围**:先因子线(IC+tail 双轨同地图),策略层(strategy_lab)后置观察。
- **D7 质量函数**:默认 dev IC_IR;ΔENB 贡献作为可选插槽(家族五不单独启动,但它是质量函数的自然候选——若 D7 选它,家族五的核心价值顺带落地)。

## 四、验收标准

1. 地图可重建性:archive 从 trail_engine 纯派生,删了能重建(与 tail_ledger 同纪律);
2. 零指令注入:所有新通道输出为事实/素材,语言审计无"应该/建议/优先"类指令词(N4 红线可检验化);
3. 反思可对账:lessons 中每个数字可回溯 trail 条目(指纹对账三件套适用);
4. 计数不变:新通道不改变任何门的输入;试验计数、bar_sigma、pool_std 口径逐一回归;
5. 行为对照:上线后 A/B(注入器 on/off)看冗余率与空格访问率——**若空格访问推高冗余率**,说明空格信号被当成指令消费,回退 D4。

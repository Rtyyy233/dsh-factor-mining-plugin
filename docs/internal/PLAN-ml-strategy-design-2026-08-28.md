## 0. 决策点

已定（对话拍板，不再重议）：

| # | 决策 | 结论 |
|---|---|---|
| M1 | 排序层三臂 | 等权 / ridge（含手工交互项）/ LightGBM（重正则） |
| M2 | 基线角色 | 等权=信号存在性参照；线性=复杂度正当性参照（G4′ 增量基线，不白跑） |
| M3 | 三臂同构 | 同 PIT 可投资池、同 top-k/全池规则、同再平衡频率、同成本模型；臂间**唯一差异=打分函数** |
| M4 | 线性臂带交互项 | 主×条件乘积（5→8-9 特征，ridge 压住）；GBDT 增量干净对应「手工低阶结构之外」 |
| M5 | NN 不进 v1 | 5 特征 × ~110 有效时间片养不起；触发条件=改喂原始序列（如 20-60d×5 通道小 GRU）或特征扩到几十个；且 seed 方差=seed lottery，每 seed 计价 |
| M6 | 择时层 v2 叠加 | 恒满仓→趋势过滤→vol targeting→（仅当规则层证明信息存在）ML 择时；排序层胜者确定后才做 |
| M7 | GBDT 不做择时 | 择时层无横截面对比（一天一个市场状态），~110 有效观测；vol 可预测≠方向可预测 |
| M8 | 计价预算 | 排序层 ~10-12 个计价试验（等权 1 + ridge 2-3 + LGBM 预注册 6-8）；择时规则预注册 3-5 条 |

## 1. 样本量账（M4/M5/M7 的依据）

面板 T=2822、N=1752 看着大，打两个折扣：

- **标签重叠**：horizon 20-60d → 相邻样本标签共享大部分未来，有效时间
  片 ≈ 2200（dev 区天数）/ 20 ≈ **110 个**。横截面每天几百 ETF 提供
  片内排序信息，不增加独立时间样本。
- **特征窄**：5 特征 ~4 正交维度（OHLCV 数据上限，见特征卡取证）。

排序层 GBDT 成立的机制是**片内对比**（每天几百个 ETF 互相比较）；择时
层没有这个结构。NN 的地盘是高维输入/大样本学表示——对 5 个已提炼的
特征它只是超参更多、方差更大、难过因果审计的黑盒。偏差-方差最优点
在低阶函数族：线性、浅树。

## 2. 排序层：三臂设计

### 2.1 嵌套增量问题（每层只对下一层负责）

1. **线性 vs 等权 = 信号存在性**：特征组合扣成本后能否打赢「什么都不
   挑」。不过则止——后面没有意义。
2. **GBDT vs 线性 = 复杂度正当性**：树找到的交互/非线性超出线性结构
   的部分值不值方差代价。GBDT 只有对 ridge 基线有净增量才入册；5 特征
   本质线性则复杂度全是噪声，这道门挡掉。

### 2.2 GBDT（LightGBM）纪律

- 深树 ≤3-4、树数少、`min_child_samples` 大；预注册 6-8 配置小网格，
  **不搞自动调参**（Optuna 一类禁止；网格扩张=新一批计价试验）
- 目标：按日分组（group=date）的横截面回归或 LambdaRank；标签逐日
  z-score 去 Beta
- 验证按时间切、**绝不 shuffle**
- refit 频率（日/周/双周）进网格——日频 refit 信号跳、换手涨；或对
  预测做 EMA 平滑
- **WF 折边界留 ≥ horizon 的 purge 间隙**（label overlap 跨折泄漏，
  strategy source 显式做，harness fold 切分不替你管）

### 2.3 通用预处理与评估

- 特征逐日横截面标准化（z-score 或 rank）——pooled 训练的前提
- 全程净口径（flat:v1，与因子层一致）
- select 段裁决 → 胜者一次性 test；**test 解读以等权臂为坐标系**——
  test 期等权走弱（熊市/风格切换）时另两臂绝对数字跟着缩水，看增量
  不看绝对收益

## 3. 择时层：v2 阶梯（排序层胜者确定后叠加）

绝对收益 = 横截面 alpha + Beta 择时，两层解耦：排序层管「买什么」，
择时层管敞口 0-100%。

1. **恒定满仓**（零假设=三臂胜者原样）：净 Sharpe/回撤即择时层增量
   参照系。
2. **趋势过滤**（聚合指数 vs 长均线，之下减仓/清仓）：1-2 超参。这是
   **择时层的「等权臂」**——这么简单的规则都无增量 → 择时信息不存在，
   ML 更学不出来（看的是同一份信息）。
3. **vol targeting**（已实现波动率倒数缩放敞口）：可靠性来源是波动
   聚集性而非方向预测；实务里绝对收益策略回撤改善大半来自这里。
4. **ML 择时**：仅当 2/3 证明信息存在；量级=逻辑回归，不是 GBDT。

纪律：

- **花园分岔警告**：择时是研究者自由度重灾区（哪条均线/什么阈值/用
  什么资产算趋势）。每条规则、每超参=计价试验；预注册 3-5 条进 select
  段裁决，不边看边调。
- **增量对照干净**：同一排序策略开/关择时，选股运气在差分里相消，
  剩下纯择时贡献（G4′ 同构逻辑）。
- **换手协调**：择时 whipsaw 是整本书上交易，一次误判吃掉排序层数周
  alpha；净评估自动惩罚，设计上择时降仓与排序换仓同日执行。

## 4. 评估口径

排序阶段看超额（vs 等权）；加择时后切绝对收益口径：净 Sharpe / 最大
回撤 / Calmar。

## 5. 执行顺序

1. 等权臂先立（regime 底色 + 两个增量问题的参照）
2. ridge → 过等权关 → LightGBM
3. select 段三臂裁决 → 胜者一次性 test
4. 择时 v2 叠加（恒满仓基线=排序胜者，不重跑）

每层失败抬高对下一层的怀疑，**不「再试个更复杂的救一救」**。

## 6. 不做的事

- 不做 NN（v1）——触发条件见 M5
- GBDT 不进择时层（M7）
- 不自动调参；网格预注册后不得扩张
- 不因择时规则不赚钱而换市场/换池——那是新问题，不是新超参

## 7. 全链路规格

### 7.1 数据与池

- env npz 同源；dev=[0,sel_end) 内 WF，test 一次性
- 可投资池 = 当日 PIT valid ∧ 流动性地板：**20 日 amount 中位数不在
  当日池内倒数 10%**（D7，相对阈值，三臂同池）
- 横截面最小宽度：当日 valid 池 **<50 → 该日跳过**（不训练不调仓，
  持仓维持）（D10）

### 7.2 特征

- registry 5 特征冻结；逐日横截面 **rank∈[0,1]**（D4，两臂同口径）
- 线性臂交互项：**全部 6 个主×条件 rank 乘积**（2×3），5→11（D8）
- 缺失：当日缺任一主特征 → 剔除该资产当日样本，**不插补**

### 7.3 标签

- close→close 前向收益（与模拟器同 convention）；**逐日横截面 z-score**
  （去 Beta/日度尺度——排序层不学市场方向）
- **不做 winsorize**（D9；逐日 z 已缩放、GBDT 稳健、ridge 吃 rank 特征；
  列为诊断可查项，不进网格）
- h=20 主打（D1）；h=60 胜者稳健性（+1 试验）；blend 内部 {20,60}
- 停牌/终止 → 标签 NaN 剔除（valid mask 管）

### 7.4 模型与损失

| 臂 | 损失 | 说明 |
|---|---|---|
| 等权 | 无 | 被动锚，regime 坐标系 |
| ridge | MSE on z-label | λ_ratio=α/n_train∈{1e-4,1e-3,1e-2}（尺度无关） |
| LightGBM | 三族损失轴 | 见网格文书；MSE=锚点 |

- top 偏置加权：当日 label 进 top k_frac → 样本权重 ×2（按已实现 label
  加权是合法监督，**按结果筛样本才是泄漏**）
- LambdaRank：group=date，label=当日 z 十分位 gain 0-9，
  truncation_level=100
- 直接组合收益/Sharpe 反传、IC-as-loss：不进（研究级，梯度噪声大、
  难过审计）
- GBDT 3 seeds {42,43,44} 均值预测（a priori 钉死，不给 seed lottery 门）

### 7.5 训练协议

- **expanding WF**：初始训练窗 3 年、按年折叠（dev≈8 个验证年）；
  purge=20d + embargo=5d（D11）
- 折边界 purge ≥ h（label overlap 防线，source 显式做）
- 训练截止 = 标签可得时刻（h=20→t−20；h=60→t−60，慢模型天然旧 60d）
- rolling 3y 窗仅作 G8 非平稳检查配置

### 7.6 多尺度合成（D6=方案 b）

- {20,60} 双模型、**各吃全部 5 特征**、同网格结构；特征-horizon 匹配
  由拟合隐式完成（60d 模型分裂自然落在慢特征上）
- 合成：s = ½·z_A + ½·z_B（各自**当日** z 后等权平均）；权重钉死，
  敏感性（30/70、70/30）= 后续计价试验
- 合成允许补偿（一强一弱胜过双平庸），换手率自然落在两纯模型之间
- **手工特征→horizon 分桶：否决**——主特征全慢、条件特征偏快，按
  horizon 分桶恰好剪断主×条件交互（特征卡的设计意图所在）
- 明确不做的合成：stacking 学习权重、时变权重（择时偷渡）、组合层
  两本书（v3+ 挂号）

### 7.7 组合构造与执行

- top **k_frac=20%**（D2，与因子层 tail 规则同口径）池内等权
- 再平衡 = h 对齐**月频**（D3；h=60 稳健性时≈季频）
- T+1、flat:v1 成本、净口径自动结算换手；score-weighted 推迟

### 7.8 评估与裁决（pre-register）

- WF 聚合：**拼接 OOS 折日收益为一条净值序列**算总指标（D13）；
  折级指标仅诊断——折数不是独立样本量（expanding 共享历史）
- 指标：净超额 vs 等权、net Sharpe、spread_ir、turnover、maxDD
- 裁决（D12）：GBDT 胜 ridge 需**增量 Sharpe 的按日 block-bootstrap
  （块长≥h）90% 下界 >0；平局归简单模型**（复杂度代价不对称）
- block-bootstrap 方差带进评估（与 placebo 互补：信息存在性 vs 估计量
  方差）；三臂差距落在彼此带内 → 裁决谨慎
- submit：harness m≥60 标签置换 placebo；GBDT 额外报 seed 方差
- 已知结构风险挂号：ETF 同指数复制品集中度，v1 接受，相关性感知 k
  留后续

## 8. 实现层约定

- **LightGBM 复现三件套**：固定 seed + 固定 num_threads +
  `deterministic=true`（`force_row_wise=true`）——否则过不了复现审计；
  库版本进指纹
- **ML source 形态**：fit 内训练、apply 出分数；模型对象生命周期 =
  单次评估进程内，无持久化需求（验证 fit/apply 契约不排斥）
- **test 期等权臂**：作为基准被测量，不占试验、不烧 test_lock（无
  超参）；只有胜者烧锁
- **网格冻结**：预注册文书另文件（GRID-ml-rank-v1-2026-08-28.md），
  跑前落、跑后不改；扩张 = 新一批计价试验

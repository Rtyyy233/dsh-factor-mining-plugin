## 0. 事故:僵尸持仓(2026-09-04 特性诊断发现)

**现象**:K2 真实路径(worker run_apply 对质)中 SZSE.150230/
SZSE.150023(分级基金,2020-12-31 清退)被持有到评估窗末——
价格数据 2021 起全 NaN,却仍在持仓 dict 中 913/904 天。

**根因链**:出场条件 `not (isfinite(vol_q) ∧ vol_q>0.85)` 对
数据消失票 vol_q 恒 NaN → isfinite 恒假 → 出场条件恒假 →
**永久持有**。权重端 var20 同 NaN → 补位时的重算给 0 权重,
但 held 恒=5 使权重从不重算 → 冻结权重(实测日均 ~1.2%)挂着
价格冻结的假持仓。

**量化**:39% 交易日带僵尸槽;有效持仓数分布 3 只×816 天/
5 只×645 天——**「5 只分散」设计近四成时间未发生**。
v1/v2/v3 交付的 2021 后数字(fold3 尾/fold4)全部带着此缺陷。

**修复**:出场条件前置「价格数据消失(退市/清盘/长期停牌)
强制出场」——`isfinite(c[t,s])` 为假即出。K2/J6/J1 三文件
同构修复;历史臂(已支配/已否决)不重跑,主形态与关键对照重跑。

**暴露路径**:诊断脚本与账本数字不符(我算回撤 39.6% vs 评估器
20.6%)→ 溯源发现诊断脚本自身 3 处 bug(vol_q 分位写反/收益错位
/NaN 计 0)与 worker 路径对质 → 僵尸现形。教训:**交付形态必须
定期用 worker 侧路径对质画像**(行为遥测前置纪律的延伸——此前
遥测都是本地重放,从未对质过评估器真实路径)。

## 1. 归因对照臂(修复基座上)

K2 的 19.8% 里反转排序 vs 低波动选择各贡献几何(逆方差实质在
押注低波动异象,Baker-Bradley-Wurgler 2011/Frazzini-Pedersen
2014 BAB 文献线):

| # | 臂 | 定义 |
|---|---|---|
| L1a | 纯低波动选票 | 排序信号归零:门过滤池按 PK 方差升序取前 30,按序补 5 |
| L1b | 排序初筛+波动选票 | lowrelhigh top30 ∧ 门(与 K2 同)→ 补位序从名次改为 PK 方差升序 |
| L2 | 权重 cap | K2 + 单票上限 40%(min(w,cap) 重归一;实务标配,砍极端集中) |

裁决:K2−L1a=排序总贡献;K2−L1b=名次序 vs 波动序的增量;
L2 若 Calmar 不降则采纳(集中度画像改善的免费午餐)。

## 2. 结果(dev,2024-09-24 截止)

### 2.1 修复重估(全部 AND2d 系历史臂的僵尸虚增被剥离)

| 臂 | 修复前 | 修复后 | Calmar 前→后 |

| K1 YZ 权重×池30 | 0.990/17.1%/18.7% | 0.596/8.7%/25.8% | 0.92→0.34(86854799) |

**修复引发的三重排序重估**:
1. 估计器:PK(0.965) >> cc(0.722) > YZ(0.596)——PK 优势从噪声级
   (+0.011)扩大到显著级(+0.243)。机制:cc 逆方差压不住池30 补位
   进来的高波动票,PK 压得住;YZ 的"回撤最浅"是僵尸幻觉。
2. 池宽×估计器协同:PK 版池30 优;cc 版池20 反超池30(J1 0.793 >
   J6 0.722)——池宽结论不独立于估计器。
3. **僵尸曾是虚增收益的**:僵尸槽阻止补位,3 只集中持仓被奖励;
   修复释放槽位、补进新票,所有臂数字下移。v1/v2/v3 的历史数字
   全部含此虚增,以本表修复版为准。

### 2.4 裁决链执行总结

- 主形态定格 **K2 修复版**(PK 逆方差+池30+AND2d 门+僵尸出场修复):
  0.965/16.7%/19.6%/Calmar 0.85。
- 归因大债已答:收益来自「反转排序选票×时序门」,低波动选择
  (L1a)与波动序补位(L1b)均不构成替代;PK 逆方差的价值在
  **权重层压波动**(不是选票层)。

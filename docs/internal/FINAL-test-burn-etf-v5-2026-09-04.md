## 3. test 窗的深层判读(诚实条款)

1. **test 窗是被动大牛市**:同窗被动基线 Sharpe 1.421/年化 43.7%
   /回撤 21.7%(924 行情+2025-26 牛市)。**策略收益与 Calmar 双输
   给满仓被动**(26.7% vs 43.7%;0.95 vs 2.02)——终审「通过」
   的含义是策略自身 alpha 形态存续(Sharpe 几乎不衰减),**不是
   样本外打败市场**;
2. **生态归因**:反转因子 IC 从 dev 末两年 −0.037 回到 test 窗
   +0.010(中性,IR 0.04)——**生态修复但仅中性**,不是 2016-19
   的强生态。策略 26.7% 的来源=「中性生态×牛市右尾」(top 端
   反弹票在牛市弹性放大),与「策略吃右尾不吃均值」理论一致;
3. 回撤 28% 集中于牛市内回调段——牛市里策略保持满仓规则、不
   做 beta 择时(三轮已证不可行),回撤特征从「熊防御」回到
   「随市波动但更浅」。

## 4. 部署结论

- **样本外确认**:alpha 结构真实存在且跨样本稳定(Sharpe 衰减
  6.4% 属噪声级);Calmar 0.95 与 dev 一致;
- **定位再确认**:这是绝对收益 18-27%/回撤 20-28% 的防御型轮动,
  不是牛市增强器——牛市里会被满仓被动碾压,价值在熊段与震荡段
  (滚动 delta Sharpe 89% 为正的证据仍成立);
- 增量门(R)对被动在同窗的 block bootstrap:delta_sharpe
  −0.45(被动 1.42 vs 策略 0.97)——**增量门正式不过**(收益
  口径),口径错配预警兑现。submit 门链裁决权在用户:接受拒收/
  风险形态口径增补/不入册。

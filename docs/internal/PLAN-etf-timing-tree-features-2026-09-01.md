## 1. 特征构造体系 v3:三层流水线

**构造总则(调研定死的五条)**:①标准化基准 = 自身长窗历史(expanding
分位/750d z),严禁任何当日截面统计混入;②单窗口构造不存在——一切
窗口参数以 {20, 60, 126} 三窗集出现,由层 C 集成;③斜率类一律 **t
统计量口径**(Quantpedia 统计理论派:按噪声归一);④每个候选的构造
档案五要素齐全(载体/构造/窗口集/后处理链/机制注记),缺一不生成;
⑤参数节俭:每特征自由参数 ≤3,邻域平坦(窗口 ±20% 扰动方向不变)
是 L0 的一部分。

### 1.1 层 A:载体(在什么序列上构造,v3.1 按业界依据重设计)

**业界依据**:Man AHL 市场组合四标准(流动性/危机状态分散/经济回报
驱动器差异/组合吸引力,回测用最流动 50 个期货);MOP-TSMOM 构造三
准则(跨资产类别/ex-ante 波动率标准化/历史充足性入样)。

**五个资产类别载体**(每类一个独立经济驱动器:债券=久期避险、黄金=
避险通胀、商品=通胀供需、海外=全球周期+汇率、宽基=增长):
- 成员 = 按**跟踪指数/资产类别归类**(非名称关键词)AND 上市 ≥252 日
  (MOP ex-ante 历史准则)AND **日均成交额 ≥2000 万流动性地板**
  (Man 第一标准);
- 每载体篮子内等权聚合收益序列,输出前**统一 ex-ante 波动率标准化**
  (EWM 估计,对齐 MOP 构造核心;Yang-Zhang range-based(OHLC)估计
  作为稳健性变体标注)——层 B 一切构造在风险可比空间进行,否则跨
  载体一致性检验被波动率差异污染;
- 每载体四条基础序列:标准化日收益、log 价格、上行/下行分解、成交额
  分位;
- 货币维度声明:无纯 FX 载体(数据所限),汇率驱动由海外篮子隐含
  承担——与业界四大类的差距写入机制注记。

**独立聚合源(非载体)**:全池横截面统计(宽度 above-MA200、离散度、
top-200 平均两两相关、新高新低差)= Goyal-Welch 的 SVAR 型市场状态
变量——只供层 B 的状态算子使用,**不参与 tsmom/斜率类序列构造**
(无独立驱动器与可投资性,混入载体是概念错误,v3 已修正)。

### 1.2 层 B:核心构造算子(业界四流派的词汇表,12 个)

| # | 算子 | 定义(对载体序列) | 流派出处 |
|---|---|---|---|
| B1 | tsmom | 三窗集各自累计收益 | CTA/TSMOM |
| B2 | slope_t | OLS 斜率的 t 统计量 | 统计理论派 |
| B3 | ma_dev | 价/滚动均线 −1 | 均线法 |
| B4 | chan_pos | 现价在 N 日高低区间的位置(0-1,Donchian 型) | 通道法(申万三法之一,v1/v2 缺失,补) |
| B5 | rv | 已实现波动 | 波动族 |
| B6 | vol_ts | rv20/rv60 −1(期限结构) | 波动族 |
| B7 | asym_vol | 上行 vol/下行 vol | 非对称分解 |
| B8 | dd_depth | 距 N 日高点回撤 | 状态族 |
| B9 | under_water | 水下时间(距前高的天数 z) | 状态族 |
| B10 | eff_ratio | |净变动|/路径总长(趋势纯净度) | 路径形态 |
| B11 | rel_gap | 载体间差(如 bond_mom − eq_mom;仅篮子对) | 相对族 |
| B12 | turnover_state | 篮子成交额的自身分位 | 量能状态 |

### 1.3 层 C:集成与降噪后处理(时序特有层,截面对应物不存在)

按序应用于层 B 输出,**顺序固定**:构造 → 集成 → 平滑/确认 → 状态化。

| 步 | 算子 | 规格 |
|---|---|---|
| C1 多窗集成 | 三窗 z 合成(均值)/ 三窗同号共鸣计数(0-3) | 所有含窗口的 B 算子强制 |
| C2 平滑 | EWMA(半衰期 10 日,预注册) | 可选,标档案 |
| C3 确认 | N=5 日同号才有效(否则 NaN) | 可选,标档案 |
| C4 状态化 | expanding 分位(750 日暖机)→ 连续分位值 | 全部默认 |
| C5 差分 | 特征 20 日变化(恶化/改善方向) | 可选,标档案 |

### 1.4 离散事件特征族(一等公民,树输入的天然形态)

时序实践大量符号化/事件化(金叉死叉、突破、共振)——v2 偏连续,v3
显式并列离散族,树对离散分裂天然友好:

- **共鸣计数**:tsmom/slope_t 三窗同号数(0/1/2/3);
- **连续状态日数**:当前档位(高/中/低)已持续天数(截断 60);
- **突破状态**:chan_pos >0.8 / <0.2 布尔及其 5 日确认版;
- **事件后钟**:距上次上/下行波动率状态切换的天数;
- **共振布尔**:宽度(breadth200)与趋势(z>0)同向。

离散特征同样走漏斗;其 L0 的"切换率"检验天然宽限(见 1.5)。

### 1.5 生成规模与排除清单

- 展开上限 60 候选(五载体+聚合源 × B 算子 × C 链按机制注记预筛;D11 拍板
  60 或 40);
- **排除**:宏观估值类慢变量(Goyal-Welch 两代检验样本外惯常失效,
  不进 P0)、PEAD(个股侧)、截面隔日信号(cvv 族——机制错配)、
  份额/溢价与期权隐含(P1/P2,另议)。

## 2. 预评估漏斗 v3(L1 分两类)

L0/L2/L3 同 v2;**L1 按特征类型分轨**:

- **A 轨(跨载体可复用族,B1-B10、B12)**:同一构造在 ≥3 个独立载体
  上方向一致(秩相关)——不看标签杀伪特征的主力;
- **B 轨(相对族 B11 与离散事件族)**:本身即跨篮子/事件定义,无
  "多载体重复"可言 → 替代检验 = 时间稳定性(前/后半 dev 符号一致)
  + 参数邻域平坦(窗口 ±20%、阈值 ±0.05 方向不变)。

L2 功效预算反推卡上限(预计 ≤8-12);L3 dev 前半段一次性方向筛+
逐年符号,全额计价。

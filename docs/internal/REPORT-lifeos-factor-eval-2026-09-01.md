## 0. 结论摘要(TL;DR)

1. **15 个因子无一达到现 registry 水准**(已入册 23 因子 IC_IR 0.6-0.835;
   本次最高 |IC_IR| = 0.295)。verdict 全部 needs_review。
2. **V 系列核心信号(加速度/GRJMOM/组合/筹码)在截面排序口径下无信息**
   (column-perm |z| < 1.3 ≈ 纯噪声)。V20 实盘策略的收益来自时序门控+
   退出管理,不来自截面排序——「策略有效」与「因子有效」是两回事,
   本次正式落定。
3. **唯一真·新信息:cvv_div_dd60(收盘/日内均价乖离 ÷ 60 日回撤)**——
   IC_IR −0.295、置换 z = −12.97、年度一致性 0.86,且与全部 23 个已入册
   因子最大 |ρ| 仅 **0.131**(全场最正交)。但它是隔日级快信号
   (rank 自相关 0.03),H=20 不是它的自然持有期。
4. 动量族(dev200/mom126/残差动量)是已入册 rev60 反转族的**镜像重述**
   (ρ −0.4~−0.67)且 IC 更弱——不是新维度。
5. 原实现抓到两处前视:GRJMOM 波动地板(全样本 5% 分位)、chip123
   (rank 缺 axis=全期时序百分位)。chip123 去前视后 IC 从「有效」归零。

## 1. 方法与口径

- **面板**:dsh ETF root `~/.factor-mining`(envId=etf),全量池 1752 标的 ×
  2833 bar(2015-01-05~2026-08-28);development 区 2015~2021-12-31。
  与 life-os 历史数字**不可直接比**:原评估在进攻池(511 只,行为分类
  筛选)+ horizon=10 上做;本报告 = 全量池 + H=20 + 秩 IC(不重叠信号日)。
- **等价性门(先于评估)**:翻译版 vs 忠实原实现副本(同 env 数据):
  13/15 因子逐日秩相关 = 1.00000(逐位等价);grjmom_asym 0.99921 /
  combo_v20j 0.99903(PIT 波动地板修正的预期差);chip123_pit 0.92008
  ——差异全部来自**原实现前视**(rank 全期时序百分位),不是翻译错误。
- **两处 PIT 修正**(原样保留会在 dsh 因果门/截断审计下失败):
  1. GRJMOM `vol_floor = daily_vol.quantile(0.05).mean()`(全样本=前视)
     → expanding 逐日分位;
  2. chip123 `.rank(pct=True)` 缺 axis(默认列向=全期百分位=前视)
     → axis=1 截面百分位。
  另记录:`vol_lead_ret_20` 原始定义 `corr(V, ret.shift(-1))` 直接用未来
  收益——研究期合法、实盘不可用;V20 实盘实际用的是替代实现
  (−Δvol20,即本报告 vol_delta_neg20),未受此影响。
- **计账**:15 次评估全部走 Bridge 完整链(trail 计账、lane=etf-revival),
  平均 ~75s/因子。
- **已知失效**:deflated p / 入册硬门不可算——ETF root 的 null 地形为
  spread 改版(2026-08-26)前校准,池分布基线与现口径不匹配。任何入册
  动作前需重跑 `null-calibration`。

## 4. 分组裁决

**A 组(真截面结构,可用/可深挖)**:
- `cvv_div_dd60`——全场唯一「强 + 极正交」。方向为负(乖离小/回撤深者
  未来占优),本质是隔日-数日超买回落信号;在 H=20 下 tail 端不兑现
  (spread IR −0.23)、换手极高(自相关 0.03)。**若要开发,正确口径是
  短 horizon(1-5 日),不是 20。**
- `ret_winrate_20`(+0.288)——结构真实但与 pw15 族半重叠,增量存疑。
- `cvv_x_dd60`——top-N 净年化 +10.4%(不显著,bb z 1.59)、tail spread
  IR +0.305:多头端唯一为正的成员,慢信号,可作为组合层候选观察。

**B 组(镜像重述,非新信息)**:dev200、mom126、resid_mom、dd60_div_amtcv20
(后者 β=−0.46,防御暴露显著)。

**C 组(截面无信息,|z|<1.3)**:accel21、grjmom_asym、combo_v20j、
chip123_pit、vol_delta_neg20、efficiency_20。
**V20 实盘的信号本体全部落在此组或 B 组**——它们的价值形态是时序
门控 + 单票路径管理(MA200/阶梯止损/动量确认),不携带截面排序信息。

## 5. 对 ETF 线重启的含义(任务书 P0 判据对表)

- P0 假设「两族信号互补、彼此是新信息」——**主体证伪**:动量族在
  截面上零信息或为反转族镜像。混合特征卡路线失去原料。
- **新发现**:cvv_div_dd60 是这轮唯一的高置信新维度,但需要**短 horizon
  口径**才有开发价值。在 ETF root 上申报 H 菜单会改环境指纹并要求
  null 重校——**涉及生产 root 变更,留用户拍板**。
- 入册前置:null-calibration 重跑(ETF root 池分布基线已与新 spread
  口径不匹配);在此之前所有 verdict 停在 needs_review,不宣称显著。
- life-os 因子库其余成员(18 因子 JSON 中未翻译的弱项)原始 IC_IR 全在
  ±0.15 内,低于本轮已测成员,批量翻译的期望产出为负,不再扩展。

## 6. 限制声明

- 池(全量 1752 vs 进攻池 511)与 horizon(20 vs 10)均与 life-os 历史口径
  不同——本报告裁决的是「在 dsh 统一口径下这些因子有没有效果」,
  不构成对 life-os 历史数字的复现检验。
- 慢信号在 H=20 下天然吃亏;H=60 未测(需菜单申报,同上留拍板)。
- deflated p 层失效(null 地形口径不匹配),多重比较折减未生效——
  本报告以置换 z(截面结构)+ 年度一致性做初步裁决,结论强度以此为界。

## 一、候选完整生命周期(终裁后的全景图)

```
候选生成(机制层=journal 预注册 / 机械层=farm·随机·枚举)
   ↓ evaluate(dev)——按所属层计价
   ├─ 过线(层内价格) → submit → 正常门链 → 入册
   ├─ dev 优异但未过线(near-miss)
   │    ├─ 通道③:规则化组合复活 → 组合门 → 入册(组合条目)
   │    └─ 未被③复活 → 备用线(候补池视图,派生)
   │         ├─ 通道①:重定价赦免(B 上线一次性) → 复活者走 submit
   │         └─ 通道⑤:前向孵化 → 120 日新数据终审
   │              ├─ 存活 → submit(dev p 豁免,标注 incubated_admitted)
   │              └─ 死亡 → 证伪池(供机制层经验 null)
   └─ dev 平庸 → trail 留痕(教训/证伪)
```

原则一句话:**拒绝记录的是"此刻不够",不是"永远不行";复活是条件变化的结果,不是说服的结果(agent 全程无申诉权)。**

## 二、组件一:方案 B — 分层 deflation(已认可,设计定稿)

**层**:机制层(journal 预注册假设及原始构造)/机械层(其余一切)。判定靠 `registered_ledger.jsonl`(镜像翻转瞬间追加:hash/registered_ts/eval_ts/复杂度指纹/lane),零语义解析零信任。

**三重锁**:①层内 M 自付(注册垃圾抬自己层的墙);②复杂度条件 null(折扣来自"少自由度×早承诺"乘积,标签伪装无效——pool_std(c) 曲线从 null 景观按算子数回归);③时机验证(registered_ts 早于 eval_ts,补票无效)。

**统计**:层内 bar_sigma(本层试验的实测 R 子矩阵 E[max|X|],采样器代码复用);α 层间 Šidák 分裂 ≈0.0253(复用跨轨先例);双轨复合时四次方(0.0127,影子期后再定)。

**机制层 null 两段式**:先验=复杂度回归曲线(第一天可用);经验=台账死者的 IC_IR 实测(只收死者与未决,**绝不收通过者**——v4 污染教训的镜像条款),贝叶斯收缩衔接。

**变体定价**:注册假设的参数变体无自己的注册→机械层喷雾价(核心便宜,调参贵;S1 同构门继续拦换皮)。

**接线**:mirror_hook 追加台账(null_landscape 补存 ops 字段+拟合曲线)→_trial_stats 加 stratum 参数→submit 门控按层重算→遥测双价。

**上线纪律**:影子模式先行(只算只报,门不变)1-2 个挖掘夜→分布审查→翻转。**门永不当天翻转。**

## 三、组件二:候补线(备用线)= 派生视图

deepdig 引擎化:trail(near-miss 谓词)+journal(resolved-stale 注册落败者,B 档带预期与签名)+registered_ledger 联合派生,**零新事实源,随时可重建**。A 档=裸 near-miss,B 档=注册落败(复活信息最全)。老化=排序(近度×分数),无硬过期。registry 保持纯净(只收入册者)。

谓词初值照抄 deepdig(|IC_IR|≥0.75 且 p≤0.7 且 ic_n≥40),分层上线后按"层内未过线"重校准。

## 四、补救通道

**通道①|重定价赦免(一次性)**。绑定 B 影子期收官:候补池全体按层内价格重算,复活者走正常 submit,遥测标 `repriced_admitted`。合法性条件钉死:**新价格事前可辩护(拟合于景观/复杂度,绝不动 near-miss 名单调参)**——影子期数据即为审计证据。

**通道③|规则化组合准入**。预注册一条机械规则(初版:候补池内两两 |ρ|<0.3、按层内分数取前 K=3-5、等权),规则本身注册进 journal(dof=1,机制层价格);每期执行计一次试验;组合走 evaluate_composite + 正常门链(同构/正交照旧);入册为组合条目,标注轨别(先 IC 轨)。**禁止 agent 挑成员**——组合的低价来自规则化,挑组合=argmax 复活。

**通道⑤|前向孵化(终审)**。

- 入队:候补线成员,源码 hash 冻结(孵化期禁改,改=新候选重排);
- 计值:引擎日更增量计算因子值与 IC,**中间数对 agent 不可见**(防孵化期偷调——"看一眼都是消耗"的孵化镜像);
- 判决:预注册窗口(初值 120 交易日)到期,cohort 一次性检验:IC_IR 单侧,α 按批内 K Šidák 校正。功效预算:120 日下复活线≈IC_IR 0.26(vs dev 墙 1.2,4.6 倍折扣来自"新数据无选择影子");
- 存活→submit(dev deflated p 豁免,标注 `incubated_admitted`);死亡→证伪池,尸体供机制层经验 null(⑤与 B 互相喂养);
- cohort 选择权归 agent(**统计免费**——dev 选择不污染新数据;代价仅孵化槽位),容量 20-50/批;
- test 区默认不参与拯救(特批通道人工拍板才开,默认关)。

**通道②(账本变更→正交重检)**:未拍板,依赖持续监控(未建),列为远期可选件——与"入册后持续监控降权"同批考虑,单独上②无意义。

## 五、前置批次 P0:生成侧双奖励(治未病,先于一切补救)

补救体系救的是已产生的假阴性;双奖励在生成端**减少假阴性的流入**——试验相关性低 → 实测 R 矩阵稀疏 → bar_sigma 自动下降(deflation 多样性红利);构造简单 → null 窄 → 方案 B 下定价便宜。与批次 0/1 无依赖,最先开工。

**P0a|不相关性奖励(novelty,farm 选种)**。现状=farm.py 每周期"top-k IC 排序+top-k spread 排序"选种——argmax 模式,同质化的机械入口(AlphaSAGE 点名批评)。修订:

```
选种分 = rank(|IC_IR|) + λ·(1 − max|ρ|)
ρ = 该候选与【本周期已选种子 ∪ 最近 K=5 周期已选种子】的 IC 序列相关最大值
   (sketch 从 trail_engine 取,零新增基础设施)
λ 线性退火:周期内早期重探索,后期让质量说话
```

**P0b|低复杂度奖励——已判死(2026-09-14 用户终裁,原设计撤回)**。GP 系文献与 MCTS 论文同指:机械搜索产出过复杂公式(过拟合载体)。两端落:

- 选种端:选种分加复杂度项 `− μ·max(0, ops − ops_ref)/ops_ref`,并设硬顶 ops_max(超复杂直接不选);设复杂度**下限**防空洞(单字段无信息)——奖励简洁不是奖励空洞;
- 生成端:random_generate 树生成加浅树先验(深度/算子数偏置,菜单算子带复杂度权重)。

> **终裁(2026-09-14)**:P0b 整体下线,受控校准取消。证据链(脚本
> `complexity_vs_withinbin_corr.py`,两线 2828/2851 条 random 试验):
> ①计价端——pool_std(c) 的前提"宽度随复杂度变化"不存在:符号值 σ 分五档
> 持平(IC 线 0.451~0.470);REPORT-p0-estimation 的"σ 斜率"实为
> E|X|/√(2/π) 矩估计=平均幅度换皮,已撤回;唯一存在的幅度斜率(最简档
> mean|IC_IR| 0.45 vs 0.40)是简单变换落在动量/反转/波动真信号域的落点
> 效应,按 pool_std v4 原则(真信号不定价为 null)恰恰不许收价。
> ②生成端反向指示——最简档组内 |ρ̄| 最高(0.361/0.343,|ρ|≥0.6 近重复
> 20.5% 全场最高;复杂空间组合爆炸各走各的,0.28~0.32 无上升趋势):
> 简单空间是复读机,浅树先验会推高同质化,与 P0a 正面对撞。
> ③复杂度的全部统计效应(组内相关/近重复)经 R 矩阵已被墙隐式定价,
> 不需要任何显式旋钮。
> **连带**:方案 B 三重锁之②"复杂度条件 null"同步撤除,锁降为两重
> (①层内 M 自付+③时机验证)——生产预估已证明机制层折扣仅靠①即成立
> (0.94/0.79),复杂度项本就是增强不是前提。

## 六、遥测与红线

**遥测**:层间墙高/试验数/过门率;登记率(注册协议执行度);候补池深度与流速;①复活数与名单;③组合条目表现;⑤孵化存活率与死亡去向;`repriced_admitted`/`incubated_admitted` 标注全覆盖可审计。

**红线**:门永不当天翻转;registered_ledger 独立存放**不可 reset**(与 ledger.json 同级待遇);孵化源码冻结+中间数不可见;test 区默认不参与拯救;层内 M 计数一分不减(全局计账诚实);证伪池语义不变(想法级死亡不复活,通道救的是证据级未熟)。
